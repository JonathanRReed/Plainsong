# Plan: Verify and Ensure All ASR/STT Models are Working

## Summary
This plan outlines steps to verify and ensure all 4 ASR/STT providers (Whisper, Parakeet, Canary, Distil Whisper) are properly configured and working in NautilusBot.

## Current ASR Providers in NautilusBot

| Provider | Type | Runtime Required | Model Files |
|----------|------|-----------------|-------------|
| Whisper | Native Rust | None | `ggml-*.bin` (HuggingFace) |
| Parakeet | Python + NeMo | `nemo.collections.asr` | `.nemo` file |
| Canary | Python + Transformers | `torch`, `transformers` | 3 files (config.json, model.safetensors, LICENSES) |
| Distil Whisper | Python + Transformers | `torch`, `transformers` | 8 files |

## Files to Check/Modify

### Key Source Files
- `nautilus-bot/src-tauri/src/asr/mod.rs` - ASR trait and provider types
- `nautilus-bot/src-tauri/src/asr/manager.rs` - ASR manager with diagnostics
- `nautilus-bot/src-tauri/src/asr/whisper.rs` - Whisper provider (Rust)
- `nautilus-bot/src-tauri/src/asr/parakeet.rs` - Parakeet provider (Python)
- `nautilus-bot/src-tauri/src/asr/canary.rs` - Canary provider (Python)
- `nautilus-bot/src-tauri/src/asr/distil_whisper.rs` - Distil Whisper provider (Python)
- `nautilus-bot/src-tauri/src/asr/python_runtime.rs` - Python detection utility

### Configuration
- Models stored in: `~/Library/Application Support/Nautilus/models/`
- Settings: `settings.json` (transcription section)

## Verification Steps

### Step 1: Check Downloaded Models
List what models are currently downloaded:
```bash
ls -la ~/Library/Application\ Support/Nautilus/models/
ls -la ~/Library/Application\ Support/Nautilus/models/whisper/
ls -la ~/Library/Application\ Support/Nautilus/models/parakeet/
ls -la ~/Library/Application\ Support/Nautilus/models/canary/
ls -la ~/Library/Application\ Support/Nautilus/models/distil_whisper/
```

### Step 2: Check Python Runtime
Verify Python is installed with required dependencies:
```bash
# Check Python availability
python3 --version

# Check for NeMo (Parakeet)
python3 -c "import nemo.collections.asr; print('NeMo available')"

# Check for torch + transformers (Canary/Distil)
python3 -c "import torch; import transformers; print('torch+transformers available')"

# Check NAUTILUS_PYTHON env var
echo $NAUTILUS_PYTHON
```

### Step 3: Test Each Provider
Run test transcriptions with each provider to verify functionality:
1. **Whisper**: Test with base.en model (if downloaded)
2. **Parakeet**: Test if NeMo is installed and model exists
3. **Canary**: Test if torch+transformers installed and model files exist
4. **Distil Whisper**: Test if torch+transformers installed and model files exist
