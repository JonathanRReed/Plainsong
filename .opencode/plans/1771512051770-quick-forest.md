# NautilusBot Production Licensing & Update System

## Objective
Implement a production-ready licensing, tier, and update system for NautilusBot with:
- Update gating by entitlement (trial or valid license required)
- Beta update channel for Friends Club tier only
- Different activation limits per tier (5 Basic, 10 Friends Club)
- Professional hosting: artifacts on GitHub Releases, manifests on nautilusbot.jonathanrreed.com
- Full CI/CD automation with signing/notarization

## Background
Tauri v2 app with existing Lemon Squeezy licensing (30-day trial, 7-day grace, progressive nag). No updater currently installed.

**3.3 Create `src-tauri/src/update/gating.rs`**
Entitlement checking logic:
```rust
pub fn can_check_for_updates(license: &LicenseState, channel: UpdateChannel) -> bool {
    // Must have valid license or active trial
    if !license.valid && !license.trial_active {
        return false;
    }
    // Beta channel requires Friends Club
    if channel == UpdateChannel::Beta {
        return license.tier == Tier::FriendsClub;
    }
    true
}
```
