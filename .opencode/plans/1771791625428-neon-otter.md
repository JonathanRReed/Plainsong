# NautilusBot Launch Audit & Code Review Plan

## Executive Summary

Critical bug identified: All dictation/transcription outputs "you" due to Whisper hallucination on silent audio with edge cases in suppression logic. Multiple high-priority issues found across dictation mode and meeting recording that need addressing before launch.

---

## Phase 1: Fix Critical Bug - "you" Transcription Issue

### Root Cause
Whisper model hallucinates "you" on silent/quiet audio. The suppression logic has edge cases that allow "you" to leak through.

### Files to Modify
- `nautilus-bot/src-tauri/src/lib.rs` (lines 5131-5143, 3924)

### Changes Required

#### 1.1 Fix Suppression Logic (lib.rs:5131-5143)
**Current code:**
```rust
fn should_suppress_low_information_dictation(
    text: &str,
    raw_duration_seconds: f64,
    raw_has_audio: bool,
) -> bool {
    if !raw_has_audio || !looks_low_information_dictation(text) {
        return false;  // BUG: Allows "you" through
    }
    raw_duration_seconds >= 0.3  // BUG: Short captures leak through
}
```

**Fix:** Always suppress low-information outputs (they're hallucinations):
```rust
fn should_suppress_low_information_dictation(
    text: &str,
    _raw_duration_seconds: f64,
    _raw_has_audio: bool,
) -> bool {
    looks_low_information_dictation(text)
}
```

#### 1.2 Increase Audio Detection Threshold (lib.rs:3924)
**Current:** `0.0015` (too sensitive, detects noise as audio)
**Fix:** Change to `0.01`

### Verification
1. Run `npm run tauri dev`
2. Test dictation with silent audio (don't speak) - should return empty, not "you"
3. Test dictation with short utterances - should work correctly
4. Test dictation with normal speech - should transcribe correctly

## Phase 2: Dictation Mode Improvements

### Files to Modify
- `nautilus-bot/src-tauri/src/lib.rs`
- `nautilus-bot/src-tauri/src/audio.rs`
- `nautilus-bot/src-tauri/src/audio/vad.rs`
- `nautilus-bot/src/components/popups/dictation-popup.tsx`
- `nautilus-bot/src/hooks/use-recording.tsx`

### Changes Required

#### 2.1 Pre-check Accessibility Permission on Startup
**Location:** lib.rs - add to app initialization
- Check accessibility permission when app starts
- Show warning dialog if not granted
- Prevents users from recording only to discover paste fails

#### 2.2 Add Audio Level Feedback During Recording ✓ CONFIRMED
**Location:** audio.rs + dictation-popup.tsx
- Emit audio level events during capture (e.g., `dictation-audio-level` event)
- Show visual waveform/amplitude bar in popup
- Helps users know mic is working (like Superwhisper)

#### 2.3 Implement Real-time VAD Auto-Stop ✓ CONFIRMED
**Location:** audio.rs, vad.rs
- Use existing `VoiceActivityDetector` during capture
- Track silence duration in capture thread
- Auto-stop after configurable silence duration (default 2.5 seconds)
- Add setting for silence timeout in `TranscriptionSettings`
- Emit `dictation-auto-stop` event when triggered

#### 2.4 Improve Thread Join Handling
**Location:** audio.rs:293-305
- Don't proceed if capture thread fails to join
- Return error instead of potentially losing samples

## Phase 3: Meeting Recording Improvements

### Files to Modify
- `nautilus-bot/src-tauri/src/lib.rs`
- `nautilus-bot/src-tauri/src/llm/*.rs`
- `nautilus-bot/src-tauri/src/db.rs`

### Changes Required

#### 3.1 Persist Auto-Analysis Results to Database ✓ CONFIRMED
**Location:** lib.rs:1400-1600, db.rs
- Add `summary` and `action_items` columns to `recordings` table
- Save summary and action items after generation
- Emit event AND save to database
- Survives app restart and frontend event misses

**db.rs changes:**
```sql
ALTER TABLE recordings ADD COLUMN summary TEXT;
ALTER TABLE recordings ADD COLUMN action_items TEXT; -- JSON array
```

#### 3.2 Fix Action Item Parsing
**Location:** llm/ollama.rs, llm/openai.rs, llm/anthropic.rs, llm/gemini.rs, llm/deepseek.rs
- Current parsing only handles `-` and `*` bullets
- Add support for numbered lists `1.`, `2.`, etc.
- Add support for nested bullets

#### 3.3 Increase Auto-Analysis Timeout
**Location:** lib.rs:1441
- Current 45-second timeout may be too short for long transcripts
- Increase to 90-120 seconds
