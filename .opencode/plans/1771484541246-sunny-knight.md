#### 1.1 Update Anthropic Model Fetching
**File**: `nautilus-bot/src-tauri/src/llm/anthropic.rs`
**Current**: Returns hardcoded list (lines 37-44)
**Change**: Implement API call to `https://api.anthropic.com/v1/models`

```rust
pub async fn list_models(&self) -> Result<Vec<String>> {
    let Some(ref key) = self.api_key else {
        return Ok(vec![]);
    };

    let response = self
        .client
        .get("https://api.anthropic.com/v1/models")
        .header("x-api-key", key)
        .header("anthropic-version", "2023-06-01")
        .send()
        .await
        .context("Failed to fetch Anthropic models")?;

    let data: serde_json::Value = response
        .json()
        .await
        .context("Failed to parse Anthropic response")?;

    let models: Vec<String> = data["data"]
        .as_array()
        .unwrap_or(&vec![])
        .iter()
        .filter_map(|m| m["id"].as_str().map(|s| s.to_string()))
        .filter(|id| id.contains("claude"))
        .collect();

    Ok(models)
}
```

#### 1.3 Update Tauri Commands
**File**: `nautilus-bot/src-tauri/src/lib.rs`

Update commands to call client methods instead of returning hardcoded lists:
```rust
#[tauri::command]
async fn list_anthropic_models() -> Result<Vec<String>, String> {
    let secret = secrets::get_provider_secret("anthropic")
        .map_err(|e| e.to_string())?
        .unwrap_or_default();
    
    if secret.is_empty() {
        return Ok(vec![]);
    }
    
    let client = llm::AnthropicClient::with_api_key(Some(secret));
    client.list_models().await.map_err(|e| e.to_string())
}
```

## Phase 4: Fix Model Autopopulation

### Current Behavior
The settings view loads models in `useEffect` hooks. Issues:
1. Models only load when settings tab is active
2. No retry mechanism on failure
3. API keys must be set before fetching

### Implementation

#### 4.1 Update Model Loading Logic
**File**: `nautilus-bot/src/components/views/settings-view-simple.tsx`
**Lines**: 370-380 (model loading useEffect)

Current code:
```typescript
useEffect(() => {
  if (activeTab !== "ai") return;
  setModelsLoading(true);
  Promise.all([
    listOllamaModels().catch(() => []),
    listOllamaCloudModels().catch(() => []),
    listOpenAiModels().catch(() => []),
    listAnthropicModels().catch(() => []),
    listGeminiModels().catch(() => []),
    listDeepSeekModels().catch(() => []),
  ])
  ...
}, [activeTab]);
```

Improvements needed:
1. Load models when API key is set, not just when tab opens
2. Add explicit refresh button
3. Show loading states per provider
4. Cache model lists to avoid repeated API calls

#### 4.2 Add Model Refresh on API Key Save
**File**: `nautilus-bot/src/components/views/settings-view-simple.tsx`

After saving API key, trigger model refresh for that provider:
```typescript
const handleSaveApiKey = async () => {
  await setProviderSecret(provider, apiKey);
  setHasApiKey(true);
  setSavingApiKey(false);
  // Refresh models for this provider
  await refreshModelsForProvider(provider);
};
```

#### 4.3 Add Better Error Handling
Show specific error messages when model fetching fails:
- Network error
- Invalid API key
- Rate limited
- No models available
